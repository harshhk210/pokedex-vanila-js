# Pokedex Project

This project is a web-based Pokedex application built using HTML, CSS, and JavaScript. It fetches Pokémon data from the [PokeAPI](https://pokeapi.co/) and displays it in a responsive grid. Users can search, sort, catch, and release Pokémon, with the caught list stored in local storage.

## Features

- **Responsive Design:** Layout adapts to different screen sizes.
- **Fetch Pokémon Data:** Uses the PokeAPI to load Pokémon details.
- **Search Functionality:** Filter Pokémon by name.
- **Sorting:** Sort Pokémon by ID or name.
- **Catch and Release:** Click on a Pokémon card to view detailed info and catch (or release) the Pokémon.
- **Modal Dialog:** Detailed view includes types, abilities, height, weight, moves, and stats.
- **Load More:** Fetch additional Pokémon using the "Load More" button.
- **Reset Caught List:** Reset button to clear all caught Pokémon.
